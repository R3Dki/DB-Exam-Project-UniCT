Triggers {
Whenever a row in the Nodes, Pumps, Pipes, Meters tables has its Status is set to 'Fault' or 'Maintenance' issue an Operation with the corresponding TargetType and TargetId, empty Description, Priority of 'Emergency' for Pumps, Nodes or Pipes and 'Normal' for Meters, set RequiredTechnicians to about 2-4 for Pumps, 2 for Nodes and Pipes and 1 for Readings.
Whenever a row in the Nodes, Pumps, Pipes, Meters tables has its Status is set to 'Online' or 'Disconnected' from either 'Fault', 'Disconnected' or 'Maintenance' set the CompletionDate of the Operation which was issued from the change of the State to 'Fault' or 'Maintenance' to current time.
Whenever a row in the Nodes, Pumps, Pipes, Meters tables has its Status is set to 'Online' from 'Install' set the InstallationDate to Current Time.
Whenever a row in the Nodes, Pumps, Pipes, Meters is instanced and its Status is set to 'Install' issue an 'Install' Operation with Priority dependant on Type, for Pumps 'Urgent', for Nodes, Pipes and Meters Important, also depending on the Type RequiredTechnicians should be in order, 4, 2 and 1 Technicians.
Whenever a row in the Operations Table has its CompletionDate set, set every TechnicianTasks' ReleaseDate associated with the finished Operation to the Current Time.
Whenever a Contract is made instance a new Meter with a random(for now and example purposes SerialNumber) and MeterType set to either 'Smart' or 'NotPresent' depending if the contract is either 'Civil'/'Industrial' or 'NonMetered'.
Whenever a Reading is created automatically make a Bill, the Reading points to the same Reading causing the Trigger, the Contract points to the Contract which references the Meter, if the Contract is Metered calculate the price based on the Reading and ProgressiveTaxation, if Non-Metered set price to the EnstablishedBillCost in Contracts, set DueDate to Current Date + 1 Month.
Whenever a Bill gets paid check if said Bill is overdue to the point the Meter was disconnected issue an 'Attach' Operation, with TargetType 'Meter' and TargetID to the Meter pointed by the Reading, set Priority to 'Normal' and RequiredTechnicians to 1, THIS HAS TO BE DONE ONLY ONCE.
Whenever a Meter is instanced check Total Flowrate of Meters(Demand) and Pumps(Supply) and if Demand is MaxAllowedFlowrateBottleneck % issue an 'Install' Operation with TargetId and TargetType set to NULL, RequiredTechnicians set to 2-4 (idk how to choose currently) and Priority 'Important'.

(maybe?)Whenever an 'Urgent' Operation is instanced, and AutomaticTechnicianAllocation is true, allocate even Technicians that are busy if there are none available, of course trying to avoid other Technicians busy with other 'Urgent' Operations and not already allocated to the current operation.
(maybe?)Whenever an Operation is instanced, if AutomaticTechnicianAllocation(in the future i may put a filter on what operations can be automatically allocated) is true, try to instance enough TechnicianTasks to fullfill the RequiredTechnicians count of the Operation, if it's a 'Measurement' check for other Technicians who have other 'Measurement' Tasks, but less than TechnicianMeasurementOperationsLimit, else assign a free Technician(no TechnicianTasks for that Technician with ReleaseDate NULL), DO NOT assign Technicians with Operations different from 'Measurements' to the current Operation.
}

Routines {
Every day check the Bills Table for Bills with PaymentDate unset and if DueDate is exceeded increase BillAmount by OverdueDailyBillIncrease if DueDate is exceeded by DisconnectionTimeThreshold do not increase the price any further and issue a 'Detach' Operation, with TargetType 'Meter' and TargetID to the Meter pointed by the Reading, set Priority to 'Normal' and RequiredTechnicians to 1, THIS HAS TO BE DONE ONLY ONCE.
Every day check if any Contract's BillingPeriod is met, if MeterType is Manual issue a 'Reading' Operation with 'Normal' Priority and RequiredTechnicians set to 1, TargetType set to 'Meter' and TargetId set to MeterId, THIS NEEDS TO BE DONE ONLY ONCE.
Every Month instance a Salary for every Technician, with WageAmount set to the Wage of the Technician.
}
