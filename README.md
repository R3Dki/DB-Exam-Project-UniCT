# Requirements and Setup

The only 2 requirements are: POSTGRESQL and PGCron. <br>
After the DB has been set up and created these files should be executed in the following order:

* setupdb.sql
* schema.sql
* triggers.sql
* schedules.sql
* views.sql

### Now the setup is completed.
Run 'values.sql' to load test values in the database.
